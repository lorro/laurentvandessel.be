# Building a Modern Personal Site with Astro

After years of running a simple Gridsome/Vue 2 site, I decided it was time for a refresh. I chose [Astro](https://astro.build) as the foundation and I'm glad I did.

## Why Astro?

Astro ships zero JavaScript by default, which is perfect for a mostly-static personal site. It also has excellent Vue.js support via the `@astrojs/vue` integration, so I can use Vue components where I need interactivity.

## The Tech Stack

- **Astro 6** — static site generation, content collections, MDX support
- **Tailwind CSS v4** — utility-first CSS with the new CSS-first config
- **Vue 3** — interactive islands where needed
- **Resend** — for the contact form

## What I Learned

The move from Vue 2 (Gridsome) to modern Astro was surprisingly smooth. The content collections API is excellent for managing blog posts and page content. Tailwind v4's CSS-first approach took a little getting used to but I prefer it now.

I'd recommend Astro to anyone building a personal site or small business site where performance matters.
